Niarad — Production RAG Pipeline & AI Assistant

// faiss · langchain · huggingface embeddings · multi-stage routing

/* */ A document-aware AI assistant built on a full RAG stack: FAISS vector store, HuggingFace embeddings, LangChain orchestration. Multi-stage intent routing classifies each query (small-talk / extraction / synthesis) so the right retrieval path runs — reducing unnecessary LLM calls. Input filtering and visible refusal badges keep the assistant on-domain.

/* */ Why it's here: this is a production RAG architecture, not a tutorial. Chunking strategy, embedding model choice, retrieval tuning, and intent routing all had to be decided and justified. Applied to a real use case — a study assistant for university documents — so every tradeoff was felt.
