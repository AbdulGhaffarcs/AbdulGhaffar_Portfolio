Niarad — Safe LLM Deployment & RAG

// privacy-first rag · guardrails · multi-stage routing

/* */ A document-aware AI assistant built on a full RAG stack — FAISS vector store, HuggingFace embeddings, LangChain — with an explicit safety layer in front. Topic-blocking input filter intercepts off-domain queries before they reach the LLM, multi-stage routing classifies intent (small-talk / extraction / synthesis) to minimize wasted LLM calls, and refusals are surfaced visibly in the UI as a "BLOCKED" badge.

/* */ Why it matters: safe LLM deployment is becoming its own discipline — input validation, refusal legibility, prompt-level guardrails, on-device inference for sensitive data. Niarad is my hands-on study of those primitives, applied to a real use case (a study assistant for university documents).
